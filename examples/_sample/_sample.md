## Purpose

This handbook explains how the team writes, reviews and publishes documents. It is exported from an Obsidian vault with ope.

> [!tip] Where to start
> New team members read the first two sections in their first week.

## Review steps

| Step | Who      | When               |
| ---- | -------- | ------------------ |
| 1    | Author   | Before the review  |
| 2    | Reviewer | Within three days  |
| 3    | Owner    | Before the release |

### Checklist

- [x] Spelling checked
- [ ] Links checked
- [ ] Version set

## Publishing

Every release gets a version number and a date. The footer of each page shows both, so readers know which version they hold.
